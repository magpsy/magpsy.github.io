# Chih-Yu Maggie Jao — personal website

This is a standalone, dependency-free GitHub Pages homepage in `index.html`. The About me and Research buttons switch views in place without opening another page or scrolling down. The former `research.html` URL redirects to the Research view. The LaTeX CV source remains in the private `magpsy/CV` repository. The homepage CV button links to the published one-page PDF in `magpsy/CV-public`.

## 更新方式

直接編輯 `index.html` 後，上傳至公開的 `magpsy/magpsy.github.io` 儲存庫。首頁姓名下方放較小字級的個人介紹，以及並排的 About me、Research、CV、Copy email 按鈕。About me 與 Research 在同一頁原位切換畫面，不會另開分頁或捲動至頁面下方；CV 連到一頁版 PDF，但按鈕只顯示「CV」。About me 分為 01 / Profile 與 02 / Awards：前者以預計 2028 及 2025 為學歷時間軸節點，不列 GPA 或指導教授；後者列 2025 生科系書卷獎與 2024 國科會大專研究計畫。Research 分為 01 / Research interests 與 02 / Publications & Presentations：前者有 Computational social neuroscience、Social alignment、Natural language processing 三張附說明的主題卡；後者以獨立卡片收錄 CV 的五筆研討會成果。原 `research.html` 只負責將舊連結導回首頁的 Research 畫面。若 CV 內容更新，先更新私人 `magpsy/CV` 的 LaTeX 與 PDF，再同步 PDF 至公開的 `magpsy/CV-public`。
