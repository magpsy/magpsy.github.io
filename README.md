# Chih-Yu Maggie Jao — personal website

This is a standalone, dependency-free GitHub Pages homepage. The website itself is a single `index.html`; the LaTeX CV source remains in the private `magpsy/CV` repository. The homepage links to the published one-page CV PDF in `magpsy/CV-public`.

## 更新方式

直接編輯 `index.html` 的頁首 Profile、Education、Research、Selected work 區塊後，上傳至公開的 `magpsy/magpsy.github.io` 儲存庫。姓名下方放完整的 Profile 介紹，不另設重複的 About me 文字。Education 以預計 2028 及 2025 為時間軸節點，不列 GPA 或指導教授。Research 只列 Computational social neuroscience、Natural language processing、Social alignment 三張主題卡，不另加興趣總述。學歷與成果採直式時間軸；頁首提供一頁版 CV PDF 與信箱入口，頁尾沒有獨立的 CV 或 Contact 區塊。若 CV 內容更新，先更新私人 `magpsy/CV` 的 LaTeX 與 PDF，再同步 PDF 至公開的 `magpsy/CV-public`；首頁使用固定公開連結，通常不需修改。
